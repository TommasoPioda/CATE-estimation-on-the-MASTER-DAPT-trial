# `run_archive/`

Two kinds of entries live here:

- **Dated snapshot folders** (e.g. `2026-08-12_pre-tuning-fix/`) — a deliberate, one-off freeze
  of notebook/script output kept for comparison against a later state. Each has its own README
  explaining why it exists. Nothing in these is regenerated automatically.

- **`runs/`** — auto-generated by `mechanism2_repeated_runs.py`, `mechanism3_repeated_runs.py`,
  `mechanism4_5_repeated_runs.py` and `mechanism2_statistics.py` (via `run_archiving.py`). Every
  execution gets its own `runs/<timestamp>_<script>/` folder holding that run's full stdout+
  stderr transcript (`run.log`) and a copy of whatever it saved. The canonical flat file each
  script writes at the top of `online-learning/` (the one notebooks and chapter 8 actually read)
  is unchanged and still gets overwritten on every run; the copy in `runs/` is the only place a
  past run's output and log survive the next run. `runs/` is not tracked by git (`*.parquet` and
  `*.log` are already gitignored) — it is a local run history, not a checked-in archive.

## Loose files migrated in here

- `2026-08-12_no-exploration-variant/results_policy_comparison_no_exploration.parquet` — an
  early variant run, superseded by `results_policy_comparison_full.parquet`; no notebook or
  script reads it anymore.
- `2026-08-15_superseded-by-full/results_policy_comparison.parquet` — an intermediate run
  before the `_full` suffix convention was adopted; superseded the same way.
