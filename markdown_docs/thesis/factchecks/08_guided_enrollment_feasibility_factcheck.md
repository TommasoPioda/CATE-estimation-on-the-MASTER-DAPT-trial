# Fact-check: `chapters/08_guided_enrollment_feasibility.tex`

(the six/seven-policy whole-pool sweep) and `online-learning/03_online_learning_duel_bandits_refactored.ipynb`

## Headline finding, read this first

Every number in this chapter that could be checked against a **surviving on-disk artifact**
checked out **exactly** — Table ch8-drift, the greedy column of Table ch8-outcomes, the AUTOC
lower-bound paragraph, and the greedy-configuration mirror-test statistics quoted in prose all
reproduce to the last printed digit from `online-learning/results_policy_comparison_no_exploration.parquet`
(30 runs/policy, canonical ISCH_WEIGHTS). This is strong evidence the chapter was written
honestly against a real completed run.

However, **`online-learning/05_online_learning_policy_comparison_exp.ipynb` has since been edited
and re-run** (git commit `3c441c7`, "Run checkpoints", today) in ways that no longer match the
chapter:
- `N_RUNS` was changed from **30** (the value that actually produced every verified number) to
  **100** (`05_online_learning_policy_comparison_exp.ipynb:771`) — and the chapter's own line 68
  now says "100 independent seed cohorts," directly contradicting every one of its own table
  captions two sections later, which correctly say "30 seed cohorts."
- `ISCH_WEIGHTS` was changed from the canonical `{death:0.2, mi:0.4, stroke:0.4}` to an
  MI-only `{death:0, mi:1, stroke:0}` (`05_online_learning_policy_comparison_exp.ipynb:229-230`).
- The re-run's second (greedy) pass never completed (0% progress, no `execution_count`), and the
  completed 100-run tempered pass **overwrote** `results_policy_comparison.parquet` — the same
  filename the original 30-run tempered pass used. The tempered-configuration source data behind
  Table ch8-mirror and the tempered column of Table ch8-outcomes therefore **no longer exists on
  disk** and could not be independently re-derived this session.
- A second, separate and substantive issue: the "mechanism" paragraph (lines 31-39) claims the
  chapter's mechanism "differs from every mechanism introduced [in Chapter 3]." Chapter 3, as
  rewritten, defines Mechanism 1 ("the ideal ceiling") in terms that are **structurally identical**
  to what Chapter 8 describes, and explicitly earmarks Mechanism 1 as the setting for comparing
  candidate scores. This claim is not accurate as written — see row for L31-39 below.
- A third issue: the "tuned forest of Chapter 6" that the chapter repeatedly says is the
  reference/yardstick model is, in the code, the shared **light default** forest
  (`DEFAULT_CF_PARAMS`), not a loaded, Optuna-tuned Chapter-6 model — see row for L76-78/L301-302.

None of this changes the qualitative conclusion of the chapter (the machinery selects on
noise), and the numbers as printed are almost certainly the real output of a real run — they are
just no longer reproducible from the current state of the notebook, and the code the notebook
now contains would mislead a reader trying to verify them.

## Needs the author's attention

- **L35-39.** The claim that this chapter's mechanism "differs from every mechanism introduced [in Chapter 3]" is not accurate against the rewritten Chapter 3: it is structurally identical to Chapter 3's own Mechanism 1 ("the ideal ceiling," `chapters/03_enrollment_verification.tex:135-142`), which Chapter 3 already earmarks as the setting for comparing candidate scores. This paragraph appears to be the stale pre-rewrite framing the user asked to check for; recommend rewriting it as "this chapter applies Mechanism 1... with a fixed batch of 100 and six candidate scores" rather than claiming novelty.
- **L68.** "100 independent seed cohorts" contradicts every table caption in the same chapter ("30 seed cohorts" / "30-seed average"), and contradicts the actual archived data (`results_policy_comparison_no_exploration.parquet`, 30 runs/policy) that reproduces every one of those tables exactly. The current notebook code (`N_RUNS = 100`, `05_online_learning_policy_comparison_exp.ipynb:771`) was changed after the chapter's numbers were generated (git commit `3c441c7`, today) — recommend correcting L68 to "30."
- **L76-78, L85, L301-302.** "The tuned forest of Chapter 6" (used repeatedly as the name for the reference/yardstick model) is, in code, the shared light-default preset (`DEFAULT_CF_PARAMS`, `max_depth=4`, `n_estimators=200`), not a loaded Chapter-6 Optuna-tuned model. Recommend either loading the actual Chapter 6 tuned model for this role, or correcting the prose to describe it accurately (a fixed, untuned reference forest, deliberately different from the online model so it can't move with the thing it measures — which is still a defensible design, just not what's currently written).
- **Table ch8-mirror and the tempered column of Table ch8-outcomes.** The 30-run tempered source data that produced these numbers has been overwritten on disk (same output filename reused by today's unrelated 100-run/MI-only re-run of `05_online_learning_policy_comparison_exp.ipynb`). The numbers are very likely genuine — every other number in the chapter that could be checked against surviving data matched exactly, including the parallel greedy-configuration statistics quoted right next to these (r=−0.114/p=0.829/intercept−45, reproduced bit-for-bit) — but they are not independently re-derivable right now. If the notebook is re-run for any other reason, consider re-saving the tempered 30-run output under its own filename before it's overwritten again.
- **L229-234 (ρ=0.91/0.44, 58%).** Only found as asserted text in two docstrings (`online_learning_utils.py:182-187` and `:240-242`), not as the output of an executed correlation cell in any current notebook.
